# Apes Textures

A collection of [Apes.io](https://apes.io/test) textures, along with a script for extracting images from the game's `.tex` files.

# Download the textures

## Clone the repository
```bash
git clone https://github.com/pseudoical/apes-textures.git
```

## [Download the ZIP](https://github.com//pseudoical/apes-textures/archive/refs/heads/main.zip)
```text
https://github.com//pseudoical/apes-textures/archive/refs/heads/main.zip
```

# Extract the textures

```bash
node ./src/textures.mjs
```

> Download the `.tex` files if needed and extract textures.

```bash
node ./src/textures.mjs --fetch
```

> Force download the `.tex` files and extract textures.
